# Bucket List Motivator

## Description

The Bucket List Motivator is a simple website that helps users track and manage their bucket list items. The site allows users to add and remove tasks from their list, and each time a task is added or completed, a motivational quote is displayed to inspire and encourage them on their journey.

## Features

- **Task Management**: Add and remove items from your bucket list.
- **Motivational Quotes**: When a task is added or completed, a random motivational quote is displayed to keep you motivated.
- **Simple UI**: Clean and straightforward design to make adding and managing tasks easy.

## Technologies Used

- **HTML**: For the basic structure and layout of the website.
- **CSS**: For styling the website and providing a visually appealing interface.
- **JavaScript**: For the interactive features, including adding/removing tasks and displaying motivational quotes.

## How to Use

1. **Add a Task**: Type the task you'd like to add in the input box and click the "Add Task" button.
2. **Remove a Task**: Tasks can be removed by clicking the delete button next to each task.
3. **Receive Motivation**: After adding or removing a task, a motivational quote will appear to encourage you.
